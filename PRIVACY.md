# Privacy Policy

_Last updated: November 17, 2026_

Application Agent is a personal tool. I built it to help with my own job search, and I'm the only person who uses it. It isn't offered to anyone else, and nobody else can sign in to it.

## What it accesses

When I sign in with Google, the agent asks for two permissions:

- **Google Sheets:** it reads and updates the one spreadsheet I use to track job applications.
- **Gmail, read-only:** it reads emails about my job applications (confirmations, rejections and interview requests) so it can update that spreadsheet. It can't send, delete, or change any email.

## Where the data goes

Everything stays on my own computer. The agent saves its sign-in token and its own records in a local folder that is never uploaded to GitHub or anywhere else.

Nothing from my Google account is sold, shared, or used for advertising. No other person or company receives it. Email content isn't used to train AI models. The essay drafts the agent writes come from a model that runs on my own machine, and it never sees my email.

## Removing access

Access can be revoked at any time from [Google Account → Security → Third-party connections](https://myaccount.google.com/connections). Deleting the agent's local folder removes everything it has saved.
